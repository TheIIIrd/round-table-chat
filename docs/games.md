# Игры

Партию ведёт бот. Все команды начинаются с `!`, у каждой есть русский синоним.

## Лобби

| Команда            | Что делает           |
|--------------------|----------------------|
| `!game`            | список доступных игр |
| `!game durak`      | собрать партию       |
| `!join` / `!leave` | записаться или выйти |
| `!start` / `!stop` | начать или прервать  |
| `!who`             | кто играет           |

Русские синонимы: `!игра`, `!войти`, `!выйти`, `!начать`, `!стоп`, `!кто`.
Названия игр тоже: `дурак`, `мафия`, `виселица`, `четыре`.

Сбор отменяется сам через три минуты, если никто не начал. Одна активная партия
на группу.

## Четыре в ряд — `c4`

Двое. `!drop 4` — поставить в столбец, `!board` — посмотреть доску.
Синонимы: `!ход`, `!доска`.

На ход даётся две минуты, за тридцать секунд приходит предупреждение. Не
сходил — поражение. Ушёл из партии — победа достаётся сопернику.

## Дурак (подкидной) — `durak`

От двух до шести человек.

| Команда       | Синоним      | Что делает                |
|---------------|--------------|---------------------------|
| `!attack 6♥`  | `!ход`       | первый ход                |
| `!add 6♣`     | `!подкинуть` | подкинуть                 |
| `!beat 8♥ 6♣` | `!бить`      | отбить своей картой чужую |
| `!take`       | `!взять`     | забрать со стола          |
| `!pass`       | `!пас`       | сказать «бито»            |
| `!hand`       | `!рука`      | посмотреть свою руку      |
| `!table`      | `!стол`      | посмотреть стол           |

**Ввод снисходителен к человеку.** Масть можно назвать как угодно: `6т`, `6к`,
`6c`, `6♣`. Латинские `p` и `B` понимаются как `п` и `В` — промах раскладкой не
повод отказывать. Если карт такого достоинства в руке одна, масть указывать не
нужно: `!attack 10`. Если несколько — игра не гадает, а перечисляет варианты.

Несколько карт кладутся одной командой: `!attack 6♥ 6♣`. Если вторая не проходит
по правилам, первая остаётся на столе, а вы получаете объяснение по второй.

Под столом бот показывает, что каждый может сделать прямо сейчас:

```
┌─ Стол · козырь ♥ ─┐
│ 6♥/· 6♣/·         │
└─ колода 18 · отбой 4 ─┘
alice: !add <карта>, ждём защиту
carol: !beat <своя> 6♥   !take   !hand
```

**Реализованные правила:** 36 карт, козырь по нижней карте колоды, первым ходит
обладатель младшего козыря, подкидывает любой участник картой того же
достоинства, на столе не больше шести карт и не больше, чем защищающийся
способен отбить, добор до шести после каждого круга в порядке «атакующий,
остальные, защищающийся», вышедшие из карт выбывают, последний с картами —
дурак.

**Не реализованы намеренно:** перевод (переброс атаки соседу) и «погоны». Они
меняют очерёдность и в разных компаниях трактуются по-разному, а спорные правила
наполовину хуже отсутствующих.

## Мафия — `mafia`

От четырёх до восьми. Роли: мафия (примерно треть состава), комиссар, мирные.

| Команда       | Синоним      | Кто и когда                      |
|---------------|--------------|----------------------------------|
| `!kill вася`  | `!убить`     | мафия, ночью                     |
| `!check вася` | `!проверить` | комиссар, ночью, раз за ночь     |
| `!day`        | `!день`      | любой, чтобы открыть голосование |
| `!vote вася`  | `!голос`     | все, во время голосования        |
| `!status`     | `!статус`    | своя роль и положение дел        |

**Ночные ходы пишите боту лично:**

```
/w dice !kill вася
```

Написанное в общий чат видят все. Игра предупреждает об этом при раздаче ролей,
но подстраховать за игрока не может.

Ночь заканчивается, когда отходили все ночные роли, либо через две минуты. День
длится четыре минуты или до `!day`. Голосование — две минуты; при ничьей никого
не казнят. Игра кончается, когда мафии не осталось или её стало не меньше, чем
остальных.

**Владелец узла с ботом видит все роли.** Разумнее всего, чтобы он в партии не
участвовал.

## Виселица — `hangman`

От одного до восьми, кооперативная, **без очерёдности**: буквы называет кто
угодно и когда угодно.

`!letter а` (`!буква`), `!word ответ` (`!слово`), `!gallows` (`!виселица`).

Семь ошибок. Буква «ё» считается за «е». Партия отменяется после пяти минут
молчания.

Это единственный случай, где бот подходит идеально без оговорок: секрет
принадлежит ему **по замыслу игры**, а не из-за компромисса.

## Как добавить свою игру

Игра не имеет доступа к сети. Она получает событие и возвращает список
намерений: `Say` всем, `Whisper` лично, `Finish` в конце. Превращает намерения в
сообщения хозяин партии — это единственное место, где игра встречается с сетью.

```python
class MyGame:
    name, title = "mygame", "Моя игра"
    min_players, max_players = 2, 4
    verbs = frozenset({"move"})                    # канонические, латиницей
    aliases = {"ход": "move"}                      # русские синонимы

    def __init__(self, rng): ...                   # случайность снаружи — ради тестов
    def start(self, players) -> list[Action]: ...
    def handle(self, player, verb, rest) -> list[Action]: ...
    def on_leave(self, player) -> list[Action]: ...
    def tick(self, now) -> list[Action]: ...       # таймауты хода
    def snapshot_for(self, player) -> str: ...     # вернулся после обрыва
```

Три шага: файл в `p2pchat/games/`, строка в `CATALOG`, тест на правила.

**Что каркас берёт на себя:** набор игроков, таймаут сбора, таймаут хода, уход
участника и возвращение после обрыва, ограничитель частоты, разбор синонимов.

**О чём легко забыть и что стоит сделать:**

- `snapshot_for` обязателен, если у игрока есть приватное состояние. Пиры
  отваливаются и возвращаются; без этого вернувшийся останется слепым.
- `tick` нужен всегда, где есть очерёдность: один ушедший иначе вешает партию.
- Инвариант вроде «карт всегда 36» стоит проверить генеративным тестом. Именно
  так нашлось, что в дураке не было отбоя и колода переставала сходиться.
- Оформляйте состояние рамкой через `format.panel` — она отделяет доску от
  потока реплик в любом терминале и переживает копирование.

**Приватная раздача достаётся бесплатно:** меш попарный, поэтому `Whisper` —
это просто отправка в личную сессию игрока, сквозь то же шифрование. Но
скрытое состояние видит владелец узла с ботом; для карт и ролей это надо
проговаривать вслух.
