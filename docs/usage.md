# Установка и повседневное использование

## Установка

```bash
pip install cryptography          # обязательная зависимость, одна
pip install prompt_toolkit        # необязательно: строка ввода не рвётся
```

Нужен Python 3.11 или новее.

## Команды запуска

```bash
python -m p2pchat keygen --nick alice          # создать ключ
python -m p2pchat whoami                       # свой ключ и отпечаток
python -m p2pchat invite --address host:port   # приглашение для других
python -m p2pchat invite --group               # приглашение со всем ростером
python -m p2pchat roster new друзья            # создать пустой ростер
python -m p2pchat roster add-invite p2pchat:…  # принять приглашение
python -m p2pchat roster add ник ключ …        # добавить вручную
python -m p2pchat roster show                  # состав и id группы
python -m p2pchat chat --listen 0.0.0.0:9333   # чат
python -m p2pchat bot  --listen 0.0.0.0:9334   # бот
python -m p2pchat colortest                    # проверить цвет в терминале
```

Общие флаги работают и до подкоманды, и после неё:

| Флаг               | Что делает                                       |
|--------------------|--------------------------------------------------|
| `--home <каталог>` | где лежат ключ, ростер, известные пиры, загрузки |
| `--no-color`       | вывод без цвета (то же делает `NO_COLOR`)        |

Флаги `chat`:

| Флаг                 | Что делает                                       |
|----------------------|--------------------------------------------------|
| `--nick`             | ник (по умолчанию из ключа)                      |
| `--listen host:port` | адрес для входящих, или `none`                   |
| `--direct host:port` | режим один на один без ростера                   |
| `--discover lan`     | искать участников в локальной сети               |
| `--plain`            | простой ввод без `prompt_toolkit`                |
| `--key-from-env`     | пассфраза из `P2PCHAT_PASSPHRASE` (для скриптов) |

## Команды в чате

| Команда                          | Что делает                                     |
|----------------------------------|------------------------------------------------|
| `/peers`                         | кто на связи                                   |
| `/verify <ник>`                  | отметить, что SAS сверен голосом               |
| `/forget <ник>`                  | забыть ключ, если собеседник переустановил чат |
| `/w <ник> <текст>`               | сказать лично — ночные ходы в играх только так |
| `/send <ник> <путь>`             | предложить файл                                |
| `/accept <id>` / `/decline <id>` | ответ на предложение файла                     |
| `/connect host:port`             | подключиться вручную                           |
| `/fingerprint`, `/help`, `/quit` | остальное                                      |

Всё, что не начинается со `/`, уходит в чат.

## Русские названия команд

Работают везде — в чате, у бота и в играх. В подсказках их нет намеренно:
перечислять по два имени на команду значит удвоить справку ради тех, кто и так
угадает.

**Чат:** `/кто` → peers, `/сверить` → verify, `/забыть` → forget,
`/подключить` → connect, `/файл` → send, `/принять` → accept,
`/отклонить` → decline, `/лично` → w, `/отпечаток` → fingerprint,
`/помощь` → help, `/выход` → quit.

**Бот и лобби:** `!игра` → game, `!войти` → join, `!выйти` → leave,
`!начать` → start, `!стоп` → stop, `!кто` → who, `!бросок` → roll,
`!монета` → coin, `!выбери` → choose, `!помощь` → help.

**Названия игр:** `дурак` → durak, `мафия` → mafia, `виселица` → hangman,
`четыре` → c4.

**Ходы:** `!ход` → attack/drop, `!подкинуть` → add, `!бить` → beat,
`!взять` → take, `!пас` → pass, `!рука` → hand, `!стол` → table,
`!убить` → kill, `!проверить` → check, `!голос` → vote, `!день` → day,
`!буква` → letter, `!слово` → word.

## Оформление вывода

Два механизма, которые важно не смешивать.

**Структура едет по проводу.** Доски, расклады и карточки ролей бот заключает в
рамки из псевдографики прямо в тексте. Их видят все одинаково и они читаются
там, где цвета нет вовсе.

**Цвет накладывается локально.** ANSI никогда не уходит в сеть: сообщение
остаётся обычным текстом, раскрашивает его клиент получателя. Реплики бота идут
с полосой `┃`, ники окрашены по **публичному ключу** (подделать чужой цвет,
назвавшись его ником, не выйдет), предупреждения красные, служебные строки
приглушены. Несверенный собеседник помечается `?` перед ником — видно и в
чёрно-белом терминале.

Весь входящий текст проходит очистку от управляющих последовательностей: без неё
любой участник мог бы прислать `\x1b[2J` и очистить вам экран.

## Файлы

Предел 64 МиБ, куски по 32 КиБ, хеш BLAKE2b проверяется целиком. Принятый файл
появляется в `~/.p2pchat/downloads` только после проверки — недоделанный не
остаётся. Имя санитизируется: `../../.ssh/authorized_keys` не превращается в
путь.

Не больше трёх висящих предложений в каждую сторону на участника. Предложение
живёт пять минут, принятая передача без движения — две.

## Где что лежит

| Файл в `--home`    | Что внутри                                          |
|--------------------|-----------------------------------------------------|
| `id.key`           | приватный ключ под пассфразой, права `0600`         |
| `roster.json`      | состав группы                                       |
| `known_peers.json` | известные ключи, отметки о сверке, последние адреса |
| `downloads/`       | принятые файлы                                      |

Переписка не сохраняется: история живёт только в памяти процесса.
